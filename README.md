# WBGT Heat Stress Monitor

Interactive safety tool for monitoring Wet Bulb Globe Temperature (WBGT) and managing heat stress risks in Singapore workplaces.

## Features

- Real-time WBGT input with slider/manual entry
- Automatic risk level classification (Low/Medium/High/Critical)
- Dynamic safety measure display based on Singapore regulations
- Hourly monitoring reminders
- Mobile-responsive design

## Risk Levels

| WBGT (°C) | Risk Level | Key Actions |
|-----------|------------|-------------|
| &lt; 31 | Low | Basic acclimatization, shade, hydration |
| 31 - &lt;32 | Medium | Hourly WBGT monitoring, 300ml/hr hydration |
| 32 - &lt;33 | High | Mandatory 10-min hourly rest breaks |
| ≥ 33 | Critical | 15-min hourly rests, redeploy vulnerable workers |
